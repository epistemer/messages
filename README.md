# messages

Message delivery for apps built on neozp: email and SMS that people receive
in their own language, delivered by a durable outbox that retries, with a
transport for development that writes files and one for tests that records.

Part of [neozp](https://github.com/epistemer/neozp). Module path
`github.com/epistemer/messages`. Nothing is built yet: the design is
[docs/brief.md](docs/brief.md) and the plan is
[docs/roadmap.md](docs/roadmap.md).
